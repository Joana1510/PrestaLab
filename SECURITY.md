# Política de seguridad

## Reporte de vulnerabilidades
No abras una issue pública. Usa **Security → Report a vulnerability** en este
repositorio o escribe al responsable del proyecto (DTIC, UTTEC).

Respondemos en un máximo de 5 días hábiles. Las versiones soportadas son la
última publicada en `main` (producción) y, mientras exista, su rama de
corrección (`hotfix/*`).

## Datos personales
PrestaLab maneja nombres, matrículas, teléfonos, fotografías y ubicación.
Nunca adjuntes datos reales en issues, PR o capturas.
